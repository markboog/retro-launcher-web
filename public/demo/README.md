# Bundled demo game

Retro Launcher includes `snake.gb`, a freely redistributable Game Boy homebrew
demo by Christian Reinbacher. It is provided to demonstrate the player without
shipping commercial game data or requiring a user ROM.

The original source is in [`source/`](./source/) and is licensed under the MIT
License; the full copyright and permission notice is in `source/LICENSE`. The
sound driver has its own redistribution terms in
[`source/sound/LICENSE.TXT`](./source/sound/LICENSE.TXT), which are retained
alongside the source.

**Controls:** D-pad changes direction, SELECT chooses the apple count, and
START begins the game. The source project and compiled ROM are from
[reini1305/gb_snake](https://github.com/reini1305/gb_snake), release `2.0`.
