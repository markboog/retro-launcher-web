# Retro Launcher Web desktop

Use the released Retro Game Suite 3.11 Program Manager HTML, CSS, icon set, window manager and accessory applications as the source of truth. Keep its original title bar, desktop, toolbar, menu placement, window chrome, keyboard navigation and window operations. The browser host layer supplies a local catalog and the game player.

The only new visible controls are in the File menu and its Open Game File dialog. The in-browser emulator opens in the existing MDI window manager. New controls inherit the original window and button classes. The original Windows-only launch command is hidden in the browser edition.

Verify startup against the released desktop. Test menu opening, game selection, the library import, an accessory window and a playable game on the project subpath. Check the existing layout on a narrow screen.
